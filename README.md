# Busari Sodiq Personal Portfolio

Vercel-ready static portfolio. Visual direction intentionally follows the IntercityXpress website: strong navy, gold/yellow accents, structured sections, work gallery, services, process, about, contact.

## Deploy
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Attach `busarisodiq.com.ng` to the Vercel project.
4. If the domain currently points to another Vercel project, change the DNS/domain assignment to this new project after the new deployment is live.

## Important
The profile image is referenced from the existing public Busari Sodiq site. For a fully self-contained deployment, download that image and place it at `public/assets/busari-profile.png`.

The included compressed videos are web-optimized versions of the uploaded 20-second clips.
